Bundled caption fonts

These app-local bold faces are derived from Google Fonts / Mooniak under the SIL Open Font License 1.1. The original license and copyright notices are included per family. Derived families are renamed with the LNKcap prefix; original credit/name records not identifying the derived family are retained. Variable fonts are instantiated at weight 700 and normal width. Maname retains its original outlines. No fonts are installed globally.

LNKcap Sinhala Impact: derived from the same Yaldevi source listed above at weight 700; renamed as an app-local face. The Reference Pop style adds a matching-color outline for a heavier look. License: yaldevi-OFL.txt.

LNKcap Post No Bills Colombo: derived from Mooniak Post No Bills Colombo Bold (https://github.com/mooniak/stick-no-bills-font). Bold Sinhala stencil typeface for urban poster captions. License: postnobillscolombo-OFL.txt.

LNKcap Atlas Chirani: derived from Mooniak Atlas Handwriting project (https://github.com/mooniak/atlas-handwriting-font). Casual expressive Sinhala handwritten script. License: atlaschirani-OFL.txt.

LNKcap Bindumathi: derived from UN-Bindumathi Sinhala Unicode font project. Playful rounded bubble dot terminals, iconic for creative captions and entertainment.

LNKcap Derana: derived from UN-Derana Sinhala Unicode font project. Bold modern geometric broadcast TV headline typography.

LNKcap Disapamok: derived from UN-Disapamok Sinhala Unicode font project. Heavy authoritative classical headline font for punchy titles.

LNKcap Sandhyanee: derived from UN-Sandhyanee Sinhala Unicode font project. Graceful curved calligraphy script for poetic and emotional captions.

LNKcap Alakamanda: derived from UN-Alakamanda Sinhala Unicode font project. Artistic modern display serif for elegant video layouts.

LNKcap Basuru: derived from UN-Basuru Sinhala Unicode font project. Contemporary crisp geometric sans for clean modern video aesthetics.

LNKcap Bhashitha: derived from AdBhashitha Sinhala Unicode font project (https://font.akasa.lk/AdBhashitha.font). Official national standard Unicode typeface by ICTA Sri Lanka.

LNKcap Sigiri: derived from AF Sigiri Sinhala Unicode font project (https://font.akasa.lk/AF+Sigiri.font). Traditional artistic Sinhala headline script.

LNKcap Sandarenu: derived from AFSandarenu Sinhala Unicode font project (https://font.akasa.lk/AFSandarenu-Regular.font). Smooth modern curved body text typography.

LNKcap Warna: derived from ICTA Large Font / Warna Sinhala Unicode project (https://font.akasa.lk/WARNA.font). Large bold clear display text typography.
